## SYSTEM OVERVIEW

Implemented a complete ECEF (Earth-Centered Earth-Fixed) attitude system that:
✓ Transforms spacecraft orientation from ECI (star tracker) to ECEF frame
✓ Computes position and attitude relative to Earth's surface
✓ Provides 3D visualization of satellite and orientation

## PHASE 1: COORDINATE TRANSFORMATION MODULE ✅

Location: `include/ecef-attitude.hpp` + `src/ecef-attitude.cpp`

KEY FUNCTIONS:

1. TIME UTILITIES
   • TimeToJulianDate() - Convert calendar time to Julian Date
   • CalculateGMST() - Greenwich Mean Sidereal Time (rotation angle from ECI to ECEF)

2. ATTITUDE TRANSFORMATIONS
   • TransformECItoECEF() - Star tracker output → ECEF frame
   • TransformECEFtoECI() - Inverse transformation
   • GetECEFAttitude() - Complete attitude with all representations

3. POSITION CONVERSIONS (WGS84 Standard)
   • GeodeticToECEF() - Lat/Lon/Alt → X/Y/Z coordinates
   • ECEFToGeodetic() - X/Y/Z → Lat/Lon/Alt coordinates

4. POINTING ANALYSIS
   • GetNadirDirection() - Vector toward Earth center
   • GetZenithDirection() - Vector away from Earth
   • GetNadirPointingAngle() - Angle between spacecraft Z-axis and nadir

5. FORMATTED OUTPUT
   • FormatECEFAttitudeOutput() - Human-readable results string

## PHASE 2: STAR TRACKER INTEGRATION ✅

Integration Pattern:
```cpp
// 1. Get ECI attitude from star tracker algorithm
Attitude eciAttitude = attitudeEstimator.Go(...);

// 2. Calculate Earth rotation (GMST)
double jd = TimeToJulianDate(year, month, day, hour, minute, second);
double gmst = CalculateGMST(jd);

// 3. Transform to ECEF
ECEFAttitude ecefAtt = GetECEFAttitude(eciAttitude, gmst);

// Output contains:
// - ecefAtt.quaternion    (ECEF frame orientation)
// - ecefAtt.eulerAngles   (RA, Dec, Roll)
// - ecefAtt.xAxis         (where X-axis points)
// - ecefAtt.yAxis         (where Y-axis points)
// - ecefAtt.zAxis         (where Z-axis points - typically nadir)
```

Orbital Parameters Supported:
• Altitude: Any altitude (typically 400 km for LEO)
• Inclination: Any inclination (51.6° for ISS)
• Latitude/Longitude: Ground position
• Julian Date: Time-based calculations

Example - ISS-like Orbit:
```cpp
// 400 km altitude, 51.6° inclination
Position3D satECEF = GeodeticToECEF(51.6, 0.0, 400.0);

// Get detailed orbital state
OrbitalState state = ECEFToGeodetic(satECEF);
// state.latitude, state.longitude, state.altitude
// state.ecefPosition (X, Y, Z in meters)
```

## INTEGRATION INTO YOUR CODE

Add to main attitude output location (e.g., lost.cpp):

```cpp
#include "ecef-attitude.hpp"

// After attitude estimation
Attitude eciAttitude = attitudeEstimator.Go(camera, stars, catalog, starIds);

if (eciAttitude.IsKnown()) {
    // Get current time
    time_t now = time(nullptr);
    struct tm* tm_info = gmtime(&now);
    
    // Calculate GMST (Earth's rotation angle)
    double jd = TimeToJulianDate(
        tm_info->tm_year + 1900,
        tm_info->tm_mon + 1,
        tm_info->tm_mday,
        tm_info->tm_hour,
        tm_info->tm_min,
        tm_info->tm_sec
    );
    double gmst = CalculateGMST(jd);
    
    // Transform from ECI to ECEF
    ECEFAttitude ecefAtt = GetECEFAttitude(eciAttitude, gmst);
    
    // Get satellite position (example: 400 km altitude)
    Position3D satPos = GeodeticToECEF(51.6, 0.0, 400.0);
    
    // Output to console
    std::cout << FormatECEFAttitudeOutput(ecefAtt, satPos);
    
    // Or export to JSON for visualization
    // (see ECEF_QUICKSTART.md for JSON export example)
}
```

## DATA STRUCTURES

struct ECEFAttitude {
    Quaternion quaternion;      // [real, i, j, k]
    EulerAngles eulerAngles;    // RA, Dec, Roll
    Mat3 dcm;                   // 3x3 matrix
    Vec3 xAxis;                 // Body X-axis direction
    Vec3 yAxis;                 // Body Y-axis direction
    Vec3 zAxis;                 // Body Z-axis (typically nadir)
};

struct OrbitalState {
    double julianDate;
    double gmst;
    Position3D ecefPosition;    // Cartesian ECEF (meters)
    double latitude;            // Geodetic latitude (degrees)
    double longitude;           // Geodetic longitude (degrees)
    double altitude;            // Altitude (km)
};

## KEY MATHEMATICAL OPERATIONS

GMST Calculation:
  GMST = f(Julian Date)
  Used to rotate from ECI to ECEF
  Result: 0 to 2π radians

ECI→ECEF Transformation:
  q_ecef = q_gmst × q_eci
  Where q_gmst = quaternion representing GMST rotation around Z-axis
  
Geodetic Conversion:
  X = (N + h) cos(lat) cos(lon)
  Y = (N + h) cos(lat) sin(lon)
  Z = (N(1-e²) + h) sin(lat)
  Where N = a / √(1 - e² sin²(lat))

Nadir Angle:
  angle = acos(z_axis · nadir_direction)

## VALIDATION CHECKLIST

Before deploying to production, verify:

☐ Code compiles without errors
  cmake star_tracker && cmake --build build

☐ Example program runs
  ./example

☐ Sample data generated
  python3 tools/ecef_data_generator.py

☐ Visualization works
  python3 tools/ecef_visualization.py --json sample.json

☐ Quaternion is normalized
  |q| = sqrt(real² + i² + j² + k²) = 1

☐ GMST in valid range
  0 ≤ gmst ≤ 2π radians

☐ Round-trip transformation gives original
  TransformECEFtoECI(TransformECItoECEF(q, gmst), gmst) ≈ q

☐ Geodetic conversion is reversible
  GeodeticToECEF(ECEFToGeodetic(pos)) ≈ pos
